Xe-Transfer Help Guide

Version 1.2 - March 2024

Introduction

Xe-Transfer is a powerful file transfer application designed for efficient and secure file transfers between folders. It features checksum verification, progress tracking, and intelligent file handling to ensure your files are transferred safely and accurately.

Getting Started

To use Xe-Transfer:

  1. Launch the application
  2. Click "Select Source Folders" to choose one or more source folders containing the files you want to transfer
  3. Click "Select Destination Folders" to choose one or more destination folders where you want the files to be copied
  4. Click "Start Transfer" to begin the process

Main Features

  • Multiple Source and Destination Support: Transfer files from multiple source folders to multiple destination folders in one operation
  • Smart File Handling: Automatically skips existing files that are identical to source files
  • Progress Tracking: Real-time progress updates with estimated time remaining
  • Checksum Verification: Generates SHA-256 checksums for all transferred files
  • Detailed Transfer Summary: Shows number of files copied and skipped

Transfer Controls

The transfer process includes:

  • Progress bars showing transfer status for each destination folder
  • Estimated time remaining for each transfer
  • Ability to cancel the transfer at any time
  • Automatic creation of necessary subfolders

Checksum File

After each transfer, Xe-Transfer creates a checksum file in each destination folder that includes:

  • List of all transferred files
  • SHA-256 checksum for each file
  • Timestamp of the transfer

Troubleshooting

Common Issues:
  • Insufficient disk space: Ensure you have enough free space in your destination folders
  • Permission issues: Make sure you have read access to source folders and write access to destination folders
  • File in use: Close any applications that might be using the files you want to transfer
