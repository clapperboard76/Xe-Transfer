Xe-Transfer Help

Introduction

Xe-Transfer is a powerful file transfer application designed for efficient and secure file transfers between folders. It features checksum verification, progress tracking, and a user-friendly interface.

Getting Started

To begin using Xe-Transfer:

  1. Launch the application
  2. Select your source folder using the "Select Source" button
  3. Select your destination folder using the "Select Destination" button
  4. Choose your preferred checksum option (MD5, SHA-1, or SHA-256)
  5. SHA-256 is the most robust checksum option, this should be optional for most users and is set by default
  6. Click "Start Transfer" to begin the process

Handling Existing Files

When transferring files to a destination folder that already contains some of the same files, Xe-Transfer uses a smart transfer approach. The app will:

  • Skip files that already exist in the destination folder
  • Only transfer new or modified files
  • Preserve existing files in the destination folder
  • Add new files to the destination without overwriting existing ones

This ensures that your existing files remain intact while allowing you to add new files or update modified ones. The transfer process is safe and won't accidentally overwrite or delete files in your destination folder.

Settings

The Settings tab allows you to configure project-specific details for your transfers. Here you can set the project name, description, and other metadata that will be included in the transfer logs. This information helps track and organize your file transfers, making it easier to manage multiple projects. The settings are saved automatically and will be used for all subsequent transfers until modified.

History

The History tab provides a comprehensive record of all your file transfers. Each entry includes:

  • Transfer date and time
  • Source and destination folders
  • Number of files transferred
  • Total transfer size
  • Project details (if set)
  • Transfer status (success/failure)

You can view detailed information about past transfers, including any errors or warnings that occurred during the process. The history is automatically saved and can be used to track your transfer activities over time.

Main Features

  • Secure file transfer with checksum verification
  • Real-time progress tracking
  • Multiple checksum algorithm options
  • Automatic checksum file generation
  • Smart file handling for existing files

Transfer Controls

The application provides several controls for managing your transfer:

  • Start Transfer: Begins the file transfer process
  • Pause: Pauses the current transfer operation
  • Resume: Resumes the transfer from where it has been paused

Checksum File

After a successful transfer, Xe-Transfer creates a checksum file in the destination folder. This file:

  • Contains the checksum values for all transferred files
  • Uses the format: filename: checksum
  • Can be used to verify file integrity later

Troubleshooting

Common Issues:
  • Insufficient disk space in destination folder
    • Xe-Transfer will detect this before starting the transfer
    • A warning popup will show the required space and available space
    • You can safely cancel the transfer at this point
  • Permission issues with source or destination folders
    • Right-click the folder in Finder and select "Get Info"
    • At the bottom of the Info window, click the lock icon to make changes
    • Enter your administrator password when prompted
    • Adjust the permissions to allow read/write access
  • Files locked by other applications
    • Close any applications that might be using the files
    • Check for open documents in word processors, image editors, etc.
    • If a file is locked, you'll see a warning in the transfer log
    • You can retry the transfer after closing the applications
Tips:
  • Ensure you have enough free space before starting a transfer
  • Check folder permissions if you encounter access issues
  • Close any applications that might be using the files

Understanding File Size Differences

When comparing the total size of files in the source and destination folders, you may notice slight differences. This is normal and occurs because:

  • Empty folders are not transferred to the destination
  • A checksum file (Xe-Transfer Checksums.txt) is created in the destination folder
  • The checksum file contains hash values for all transferred files

These differences are expected and don't indicate any problems with the transfer. The checksum file is essential for verifying file integrity, and empty folders are excluded to maintain efficiency in the transfer process.
